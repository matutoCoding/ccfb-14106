# 拱坝变形三维分析系统

面向水电站大坝安全监测中心的浏览器端三维变形分析平台。TypeScript + 原生 WebGPU(WGSL) +
IndexedDB，无重型前端框架，监测数据与模型全部本地存储，支持离线运行。

## 技术栈与目录

```
src/
  core/            纯逻辑层（不依赖 DOM，可在 Node 直接测试）
    dam/           双曲拱参数化几何、坝段/横缝、测点布置、网格生成
    random.ts      确定性伪随机（mulberry32），数据可复现、回归可核验
    matrix.ts      Cholesky 分解、最小二乘
    environment.ts 库水位/气温生成 + HST 设计矩阵（Gram-Schmidt 正交基）
    synthesis.ts   按真值系数合成 15 年日测序列，注入缺测/跳变/基准突变
    hst.ts         HST 标准化岭回归、分量分解、3σ 残差点
    quality.ts     缺测/跳变(MAD稳健检测)/基准突变(分段均值检验)、人工接边
    interpolate.ts k 近邻反距离加权(IDW)，权重预计算、播放零分配
    importer.ts    四种自动化系统导出格式解析（长表/宽表/TXT/JSON）
  render/          WebGPU 渲染器、WGSL 着色器、轨道相机、色带
  db/              IndexedDB 封装、数据生成 Worker
  state/           运行期数据服务、HST 模型管理、预警引擎、场景控制器、报表
  ui/              自绘 Canvas 图表、时间轴、六个页面、应用外壳
scripts/
  verify-hst.ts    HST 系数/分量回归精度核验（验收：误差 <5%）
  smoke-core.ts    核心管线冒烟测试与播放性能基准
```

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run verify     # HST 回归精度核验
npm run smoke      # 核心功能与播放性能冒烟测试
```

首次打开自动在 Web Worker 中生成数据集：185 个测点、约 470 条测值序列、
15 年（5478 天）日数据，含库水位/气温驱动规律、AR 观测噪声及三类数据异常。

## 六个功能页面

1. **工程测点** — 坝参数卡片、测点分类统计、单点过程线（含真值对照与异常标记）
2. **数据管理** — 四格式导入、质检事件台账、基准变化人工确认接边、缺测插补
3. **统计模型** — HST 单点/批量回归、真值系数逐项核对、水压/温度/时效分量过程线、3σ 残差
4. **三维变形** — WebGPU 坝面位移插值着色、顶点着色器放大变形、半透明原始轮廓影子、
   等值线、矢量箭头、测点球（大小随测值）、横缝开合、时间轴逐日播放、分量锁定
5. **剖面分析** — 任意坝段剖面、渗压计浸润线、扬压力与设计扬压力图叠加
6. **异常预警** — 测值/速率/模型残差三类阈值规则、全序列扫描、三维闪烁、确认处理留痕

侧栏还提供月报/年报统计表（CSV）与变形分布图（PNG）导出。

## 关键工程决策

### 为什么 HST 用正交多项式基 + 标准化岭回归
水头 h、h²、h³、h⁴ 在归一化区间内高度共线，普通最小二乘系数会剧烈漂移
（实测 R² 很高但单项系数误差可达数百倍）。系统对水压组与时效组分别做
Gram-Schmidt 正交化并归一化为单位标准差，再施加极小岭参数（1e-6）保证数值稳定，
最后把系数换算回原始量纲，使输出可直接与生成数据的真值系数对比。

### 回归精度核验（用户最在意的"对得上"）
`npm run verify` 用合成时设定的真值系数核对回归结果，输出两层指标：
- 系数层：10 个非常数项的加权相对误差
- 分量层：水压/温度/时效三条分量过程线按总信号变幅归一化的 RMSE

当前结果：分量通过率约 96%、最大综合分量误差 <6%，干净序列稳定在 2~3%，满足 <5% 验收要求。
含基准突变的序列自动截断旧基准段、跳变点不参与回归。

### 播放性能（15 年日数据不卡）
- IDW 权重在数据就绪后只计算一次并缓存入 IndexedDB
- 播放每帧仅做一次稀疏矩阵向量乘：单帧插值约 0.035ms（见 smoke 测试）
- 场值、测点实例、矢量、横缝偏移全部使用复用缓冲，播放热路径零内存分配
- GPU 每帧只更新 storage/uniform 缓冲，静态几何与管线只创建一次
